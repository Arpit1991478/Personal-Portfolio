# Arpit Singh | Portfolio

A personal portfolio website with a terminal-inspired look, built with plain **HTML5** and **CSS3**. No frameworks, no build step, no JavaScript.

I'm a first-year Computer Science student at Scaler School of Technology, and this site is one of my first HTML and CSS projects.

## Features

- Terminal-style hero section with a blinking cursor
- Sticky navigation with smooth scrolling to each section
- Sections for **about**, **skills**, **projects**, **education** and **contact**
- Photo frame in the about section, with an initials placeholder if the image is missing
- Fully responsive layout built with CSS Grid and Flexbox
- Dark theme driven by CSS custom properties, so colors are easy to change
- Accessibility touches: semantic HTML, visible focus outlines, and `prefers-reduced-motion` support

## Project structure

```
.
├── index.html   # Page markup with all CSS in an internal <style> block
├── photo.jpg    # Profile picture (add your own)
└── README.md
```

## Getting started

No installation needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/Arpit1991478/<repo-name>.git
   cd <repo-name>
   ```
2. Add a square profile picture named `photo.jpg` next to `index.html`.
3. Open `index.html` in any browser.

## Customization

- **Colors and spacing:** edit the variables at the top of the `<style>` block, inside `:root`.
- **Photo:** replace `photo.jpg`, or change the `src` of the `<img>` in the about section.
- **Content:** update the text, project cards and links directly in `index.html`.

## Deployment

Since this is a static site, it can be hosted for free on **GitHub Pages**:

1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch** and select `main` and `/ (root)`.
4. Save, and your site will be live after a minute or two.
